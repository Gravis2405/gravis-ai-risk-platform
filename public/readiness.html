PROJECT STATUS · SCOPE AND LIMITS

Platform readiness

A precise view of what the current local GRAVIS workspace supports and what requires production services or integrations.

● LOCAL DEMO · NOT DEPLOYED
What this build is

A complete local analyst workflow using sample and manually entered records, authenticated APIs, and a persistent JSON file. It does not automatically discover threats or provide a production service.

ANALYST WORKFLOWSAvailable locally

Review records, update cases, add notes, track assets, and export CSV.

DATA STORAGEPersistent on this server

Threats, accounts, settings, notes, and brand assets survive a restart.

DEPLOYMENT STATUSNot production ready

Production needs reviewed security, durable database, operational controls, and live provider integrations.

DELIVERY COVERAGE

Feature-by-feature status

“Available locally” describes the workflow in this demo, not a deployed or externally connected service.

Available Limited Not connected
▦
Dashboard and threat queueAnalyst interface
  • Responsive overview with live summary of stored records
  • Search and filter by severity, channel, status, target, type, and ID
  • Threat details, risk signals, timestamps, and evidence links
  • CSV report export with spreadsheet formula protection
▤
Cases and notesInvestigation workflow
  • Move cases through detected, investigating, reported, and resolved
  • Add timestamped analyst notes to each record
  • Recent updates appear in connected workspace sessions
  • No evidence attachments, assignment, or external notification delivery
◇
Brand assetsTracking list
  • Add and remove tracked brand names and domains
  • Store search terms in the workspace
  • The list organizes analyst work only
  • No crawler, social monitoring, app-store scan, or domain discovery
◷
Analytics and risk scoringReporting
  • Severity, channel, status, and daily record summaries
  • Documented and explainable starter scoring formula
  • Charts reflect stored sample and analyst-entered records
  • No calibration dataset, performance evaluation, or model monitoring
⌘
Authentication and settingsWorkspace API
  • JWT sign-in, hashed passwords, password update, and protected APIs
  • Admins can create, manage, and disable individual member accounts
  • Accounts are created by an admin; public sign-up, email verification, and recovery are not connected
  • No tenant isolation, WebAuthn, or production identity provider
◎
Privacy and operationsProduction foundation
  • The demo does not collect face or precise-location data
  • Notification preferences are saved, but no delivery channel is connected
  • No production database, backups, retention tooling, or audit log
  • No deployment, monitoring, incident response, or provider connectors
